# Trace Buddy (web version)

Upload all files in this folder (index.html, manifest.webmanifest, icon-180.png, icon-192.png, icon-512.png)
to any web host that uses **https://** – the camera does not work over plain http.

## Easiest: GitHub Pages (free)
1. Create a free account at github.com.
2. Click **+** → **New repository**, name it `trace-buddy`, set it to **Public**, click **Create repository**.
3. Click **uploading an existing file**, drag in all the files from this folder, click **Commit changes**.
4. Go to **Settings → Pages**. Under "Branch" choose **main** and **/ (root)**, click **Save**.
5. After a minute the page is live at `https://<your-username>.github.io/trace-buddy/`.

## On each iPhone
1. Open that address in **Safari**.
2. Tap **Share → Add to Home Screen → Add**.
3. Open Trace Buddy from the home screen and allow the camera when asked.

The last picture used is remembered on each phone.
